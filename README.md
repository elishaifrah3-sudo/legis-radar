# מכ״ם חקיקה — הוראות התקנה (בלי לכתוב שורת קוד אחת)

המערכת הזו רצה לבד, בחינם, על שרתים של GitHub. אתם רק צריכים להעלות
את התיקייה הזו פעם אחת ולהדליק שני מתגים. הכל דרך האתר, בלי טרמינל.

## שלב 1 — פתיחת חשבון GitHub (אם אין לכם)
1. גשו ל-github.com ולחצו Sign up.
2. בחרו שם משתמש, אימייל וסיסמה, אשרו את המייל.

## שלב 2 — יצירת מאגר (Repository) חדש
1. לחצו על ה-+ למעלה מימין -> New repository.
2. תנו שם, למשל `legis-radar`.
3. סמנו **Public** (חובה כדי ש-GitHub Pages יעבוד בחינם).
4. לחצו Create repository.

## שלב 3 — העלאת הקבצים
1. במסך של המאגר החדש, לחצו על "uploading an existing file".
2. גררו לתוך החלון את **כל** התיקייה שקיבלתם ממני — כולל התיקיות
   `docs`, `scripts`, ו-`.github` עם התוכן שבפנים (חשוב לשמור על
   מבנה התיקיות בדיוק כמו שהוא).
3. גללו למטה, לחצו Commit changes.

> טיפ: אם הגרירה של תיקיות לא עובדת דרך הדפדפן, אפשר גם ללחוץ
> "Add file" -> "Create new file", לכתוב את הנתיב המלא בשורת השם
> (למשל `docs/index.html`) ולהדביק את התוכן — לכל קובץ בנפרד.

## שלב 4 — הדלקת GitHub Pages (כדי שיהיה לכם אתר חי)
1. במאגר, לכו ל-Settings -> Pages (בתפריט הצדדי).
2. תחת "Build and deployment" -> Source, בחרו **Deploy from a branch**.
3. Branch: בחרו `main`, ותיקייה: **/docs**. שמרו.
4. אחרי דקה-שתיים תופיע כתובת כמו:
   `https://<שם-המשתמש-שלכם>.github.io/legis-radar/`
   זו הכתובת של הדשבורד החי שלכם — אפשר לשלוח אותה לכל אחד.

## שלב 5 — הדלקת העדכון האוטומטי (GitHub Actions)
1. לכו ל-Settings -> Actions -> General.
2. תחת "Actions permissions" ודאו שמסומן "Allow all actions".
3. תחת "Workflow permissions" בחרו **Read and write permissions**
   ושמרו (זה מה שנותן לתהליך הרשות לעדכן את הקובץ feed.json לבד).
4. לכו לטאב **Actions** למעלה. אמור להופיע workflow בשם
   "עדכון מכ״ם חקיקה". לחצו עליו, ואז "Run workflow" כדי להריץ
   פעם ראשונה באופן ידני ולוודא שהכל עובד.
5. מכאן והלאה זה ירוץ **לבד, כל 6 שעות**, בלי שתצטרכו לגעת בכלום.

## איך יודעים שזה עובד?
- בטאב Actions תראו סבב ירוק ✅ אחרי כל הרצה.
- באתר החי שלכם, למעלה יופיע "עודכן לפני X שעות" — אם המספר קטן
  מ-6-7, זה סימן שהעדכון האוטומטי פעיל.

## מה אפשר להוסיף בהמשך (לא הכרחי)
- עוד משרדי ממשלה: פותחים את `scripts/update_feed.py`, ומוסיפים
  שורה למילון `GOV_RSS_FEEDS` עם שם המשרד וכתובת ה-RSS שלו
  (כל משרד ב-gov.il חושף פיד תחת `.../RSS` בתחתית העמוד שלו).
- עוד מילות מפתח לסינון חדשות: מוסיפים לרשימת `KEYWORDS` באותו קובץ.
- שינוי תדירות העדכון: בקובץ `.github/workflows/update.yml`, השורה
  `cron: "0 */6 * * *"` — "*/6" זה כל 6 שעות, אפשר לשנות ל-"*/3" וכו'.

אם משהו לא עובד או לא ברור — אפשר להעתיק את הודעת השגיאה
מטאב Actions ולשאול אותי, ואני אעזור לתקן.
